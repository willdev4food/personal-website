HTML TAGS USED (>= 10)
1. <nav> creates a navigation bar that appears on every page.
2. <header> introduces the main content or hero section of each page.
3. <main> wraps the primary page content for semantic structure.
4. <section> groups related content into logical parts of each page.
5. <article> used for individual cards, projects, or content items.
6. <aside> displays secondary or related content beside the main content.
7. <footer> contains information and navigation links at the bottom.
8. <figure> and <figcaption> used in the gallery to pair images with captions.
9. <table> used on the About page to display the tech stack clearly.
10. <form> <label> <input> <textarea> <button> used in the Contact page for user input.

CSS PROPERTIES USED (>= 5)
1. background: defines the gradient background of the hero section.
2. border bottom and border top: adds separation lines to the navbar and footer.
3. font-weight: emphasizes active navigation links.
4. object fit: ensures consistent image sizing inside Bootstrap cards.
5. padding, margin top, border radius: control layout spacing/ edges.
